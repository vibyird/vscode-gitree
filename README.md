# Gitree for VSCode

用于增强VSCode的git能力的项目。

## 功能清单

- [x] 日志：展示基本信息、展示提交树
- [x] 提交：展示基本信息、展示文件树、撤销、差异对比
- [ ] 远程：拉取、同步、推送
- [ ] 分支：创建、删除、合并
- [ ] 标记：创建、删除
- [ ] 储藏：创建、删除、应用

## 核心技术

- 以Svelte 5框架为核心实现Webview，未引入任何UI框架，原生实现
- 使用getState和setState来保存和恢复Webview的状态，性能开销更低
- 长列表渲染使用虚拟列表的方案实现，以优化渲染性能
- 树状图，采用SVG渲染方案，每行提交使用一个SVG图展示提交树的局部
